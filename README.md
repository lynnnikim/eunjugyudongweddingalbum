# 찰칵함 — 결혼식 하객 사진 공유 앨범

하객이 QR을 찍어 사진·영상을 올리면, 모두가 실시간으로 함께 보는 웨딩 앨범이에요.
앱 설치나 회원가입 없이 웹에서 바로 동작해요.

## 페이지 구성
| 파일 | 누가 | 하는 일 |
|---|---|---|
| `index.html` (사이트 첫 화면) | 하객 | QR로 들어와서 바로 사진·영상 올리기, 다른 하객 사진 보기 (실시간) |
| `admin.html` | 신랑·신부 | QR 스티커 시트 인쇄, 사진 숨기기, 전체 ZIP 다운로드 |

`config.js`가 비어 있으면 **데모 모드**로 실행돼요. 데모 관리 비밀번호는 `1234`예요.

## 실제로 운영하기 (약 15분)

### 1. Supabase
1. supabase.com에서 새 프로젝트를 만들어요 (무료 플랜으로 충분해요).
2. **SQL Editor**에 `supabase-setup.sql` 내용을 전부 붙여넣고 **Run**을 눌러요.
   **실행 전에 맨 아래 줄의 신랑·신부 이름, 예식일, 관리 비밀번호를 바꿔주세요.**
   테이블·보안 규칙·사진 저장소·실시간 설정과 우리 앨범이 한 번에 만들어져요.
3. **Project Settings → API**에서 `Project URL`과 `anon public` 키를 복사해요.

### 2. config.js
```js
SUPABASE_URL: "https://xxxx.supabase.co",
SUPABASE_ANON_KEY: "eyJhbGciOi...",
```

### 3. Netlify 배포
폴더 전체를 app.netlify.com의 **Sites → 드래그 앤 드롭**에 올리면 끝이에요.
배포 주소(예: `https://xxx.netlify.app/`)로 들어가면 바로 사진 올리기 화면이 나와요.
QR은 `admin.html`에서 인쇄·저장하면 배포 주소로 자동으로 만들어져요.

## 알아두면 좋은 점
- **용량**: 사진은 올리기 전에 긴 변 2560px로 줄여서 한 장에 0.5~1MB 정도예요. Supabase 무료 저장소는 1GB라서 사진 1,000~1,500장 정도 들어가요. 하객이 많으면 Pro 플랜(월 $25, 100GB)을 예식 달에만 쓰는 방법도 있어요.
- **영상**: 한 개에 50MB까지 올릴 수 있어요 (무료 플랜 한도). 줄이거나 늘리려면 `config.js`의 `MAX_VIDEO_MB`와 SQL의 `file_size_limit`을 같이 바꾸세요.
- **보안**: 관리 비밀번호는 암호화(bcrypt)해서 저장해요. 하객은 사진을 올리고 볼 수만 있고, 숨기기는 관리 비밀번호가 있어야 해요. 사진은 링크를 아는 사람이면 누구나 볼 수 있어요.
- **사진 완전 삭제**: 관리 페이지에서는 "숨기기"만 돼요. 파일 자체를 지우려면 Supabase 대시보드의 Storage에서 지우면 돼요.
- **보관 기간**: 자동으로 지워지지 않아요. 예식이 끝나면 ZIP으로 내려받아 두는 걸 추천해요.
